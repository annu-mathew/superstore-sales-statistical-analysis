# Superstore Business Performance Analysis

## Project Overview

This project analyzes Superstore sales data using Python and statistical techniques to understand business performance, sales trends, profitability, and regional and category performnace.

## Objectives

-Analyze sales and profit performance.
- Apply descriptive statistics and probability.
- Performance hypothesis testing.
- Analyze correlations between numerical variables.
- Identify business trends and generate recommendations.
- Create an executive dashboard and business reports.

## Tools and Technologies

- Python
- Pandas
- NumPy
- SciPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Excel (OpenPyXL)
- PDF (ReportLab)

## Key Business Results

- Total Sales: 2,297,200.86
- Total Profit: 286,397.02
- Total Sales Records: 9,994
- Total quantity Sold: 37,873
- Average Sales: 229.86
- Profit Margin: 12.47%

## Key Insights

- Technology generated the highest sales and profit.
- West region recorded the highest sales and profit.
- Furniture had a low profit margin.
- Tables recorded the largest sub-category loss.
- Home Office had the highest profit margin among customer segments.
